Attention Variants & SSMs

Optimizing the throughput of novel attention mechanisms is one of the defining engineering problems of this model generation. Softmax attention is O(T²) and its KV cache grows without bound — so a whole frontier of sub-quadratic alternatives exists. This page traces the line from linear attention → state-space models → DeltaNet / Gated DeltaNet, and the hybrid designs (Qwen3-Next, MiniMax, Jamba) where the field has actually landed.

Prerequisite

This assumes standard softmax attention, KV cache, and the roofline from Attention: Scratch → Efficient. The recurring theme here is one trade-off: an unbounded KV cache (perfect recall, O(T²)) vs a bounded recurrent state (cheap O(T), lossy recall).

1. Linear attention: drop the softmax, gain associativity

Softmax attention computes softmax(QKᵀ)V — the softmax couples all keys, forcing you to build the full T×T matrix. Linear attention replaces exp(qᵀk) with a factored similarity φ(q)ᵀφ(k). That small change unlocks associativity: you can compute (φ(K)ᵀV) first — a fixed d×d matrix — instead of (Qφ(K)ᵀ), turning O(T²d) into O(Td²) and giving a recurrent form with constant per-token cost and no growing KV cache.

softmax:  oₜ = Σᵢ exp(qₜ·kᵢ) vᵢ / Σᵢ exp(qₜ·kᵢ)
linear:   oₜ = φ(qₜ)ᵀ Σᵢ₌₁ᵗ φ(kᵢ) vᵢᵀ  =  φ(qₜ)ᵀ Sₜ,   Sₜ = Sₜ₋₁ + φ(kₜ) vₜᵀ
Parallel form == recurrent scan (the whole trick) 

        


        

          
⚠️ The catch: bounded memory

          

            The d×d state S is a fixed-size summary of the entire
            past — unlike the KV cache, which stores every token. That's exactly why linear attention
            is cheap, and exactly why early versions underperformed on recall/associative tasks: you're
            compressing unbounded history into constant memory. Every design below is a smarter way to
            manage that fixed budget.
          

        


        
        
2. The RNN duality

        

          The recurrent form above is a linear RNN with a matrix hidden state. This is the key
          reframing of the last few years: linear attention, state-space models, and the DeltaNet
          family are all linear RNNs that differ only in how the state
          S is updated and decayed. That unification is why they share the same
          chunk-parallel training trick (compute in parallel over chunks, recur across chunks) and the
          same O(1)-inference benefit.
        


        
        
3. State-space models: Mamba & Mamba-2

        

          State-space models (SSMs) come from control theory: a hidden state evolves as
          hₜ = A hₜ₋₁ + B xₜ, output yₜ = C hₜ. Structured SSMs (S4) made
          this trainable at scale with a diagonal A. Mamba (S6)'s
          contribution was to make A, B, C input-dependent ("selective")
          — so the model can choose what to remember and what to forget per token — plus a
          hardware-aware parallel scan to keep it fast. Mamba-2 (state space duality,
          SSD) showed SSMs and linear attention are two views of the same object, letting Mamba-2 use
          matmul-heavy, GPU-friendly formulations.

4. DeltaNet & Gated DeltaNet

        

          Plain linear attention adds kv ᵀ to the state — so writing the same key
          twice makes the readouts interfere (it sums them). The delta rule (from
          classic fast-weight / online-learning theory) fixes this: before writing, predict
          the current value for the key and store only the error, so a new write for
          an existing key overwrites rather than accumulates. This is much better associative
          memory.
        

        

          linear:   Sₜ = Sₜ₋₁ + vₜkₜᵀ 

          DeltaNet: Sₜ = Sₜ₋₁ + βₜ(vₜ − Sₜ₋₁kₜ)kₜᵀ = Sₜ₋₁(I − βₜkₜkₜᵀ) + βₜvₜkₜᵀ 

          Gated DeltaNet: Sₜ = αₜ·Sₜ₋₁(I − βₜkₜkₜᵀ) + βₜvₜkₜᵀ   (αₜ∈(0,1) = decay/forget)
        


        

          

            Delta rule overwrites; linear attention interferes
            
            
            
          

          
          

        


        

          Gated DeltaNet (Yang, Kautz et al., ICLR 2025 — "Improving Mamba2 with the
          Delta Rule") adds an exponential gate αₜ for adaptive forgetting on top
          of the delta rule, plus L2-normalized Q/K and a causal conv. It's the linear-attention layer
          in Qwen3-Next, which interleaves it with periodic full-attention layers
          (~every 4th layer full) — the hybrid pattern in the next section. The mental model: DeltaNet
          gives precise error-correcting writes; the gate lets old memories decay so the fixed state
          doesn't saturate.

          Note two different escape routes: linear/SSM methods replace softmax (sub-quadratic,
          bounded state), while MLA and sparse attention keep
          softmax but cut its cost (compress the KV cache, or attend to fewer positions). MLA in
          particular is a big deal for inference — it keeps full-attention quality while drastically
          shrinking the KV cache.
        


        
        
6. Hybrids — where the field actually landed

        

          Pure linear/SSM models are efficient but weaker at exact long-range retrieval (the bounded
          state loses detail); pure softmax is expensive. The pragmatic answer that now dominates is
          the hybrid: mostly cheap linear/SSM layers with a few full-attention
          layers sprinkled in for global recall.
        

        
    
          
  • Qwen3-Next / Qwen3.5 — Gated DeltaNet layers with ~1-in-4 full attention.
    • 
          
  • Jamba — interleaves Mamba and attention (plus MoE).
    • 
          
  • MiniMax-01 — Lightning (linear) attention with periodic softmax.
    • 
        

        

          The few full-attention layers recover the retrieval the linear layers lack, while the linear
          majority keeps inference near O(T) with a bounded cache. This "best of both" is
          the current consensus — and a great thing to be able to articulate.
        


        

          
Why this matters

          

            The framing that reads as current: it's all about the fixed-state vs KV-cache
            trade-off. "Why not go fully linear?" → bounded state loses exact recall; benchmarks needing
            retrieval/in-context copying suffer, which is why hybrids keep a few softmax layers. "What did
            Mamba-2 add?" → the duality linking SSMs to attention, enabling matmul-friendly training.
            "Why is Gated DeltaNet better than Mamba-2?" → the delta rule does error-correcting
            (overwriting) memory updates, not just gated accumulation. "What about keeping softmax?" →
            MLA compresses the KV cache and sparse attention prunes positions.
          

        


        

          

            Exercise
            Chunk-parallel linear attention
            
          

          

            The recurrent form is O(T) but serial. Real implementations use
            chunked computation: within a chunk do the quadratic (parallel) form, and carry the
            d×d state across chunks. Implement it: split the sequence into chunks, compute
            intra-chunk outputs in parallel and inter-chunk contributions via the carried state, and
            verify it matches the pure recurrent scan. This is exactly how linear-attention kernels get
            both parallel training and O(T) cost.
          

        


        

          

            Local exercise
            Gated DeltaNet layer + an associative-recall probe
            
          

          

            On your machine (or extend the cells here): implement a Gated DeltaNet update with a learned
            per-token gate αₜ and write-strength βₜ, then test it on a synthetic
            key→value recall task (write N pairs, then query random keys). Compare recall vs plain linear
            attention as N grows past the state dimension — you should see the delta rule + gating degrade
            far more gracefully. Reference: FLA (flash-linear-attention) library.
