Interpretability & Viz

Interpretability is where "it works" turns into "we understand why" — and several frontier labs treat it as a core research bet tied to safety. Building an interactive visualization of model internals is also one of the best first projects in the area. The cells here compute the quantities such a viz would display.

1. Attention patterns

The most accessible window into a transformer: for a given head, the (T×T) attention weight matrix shows which previous tokens each position reads from. Distinct, interpretable patterns recur — previous-token heads (attend to t−1), positional heads, and famously induction heads (attend to the token that followed the last occurrence of the current token, implementing in-context copying). A viz renders this matrix as a heatmap over the token strings.

          A useful scalar summary for a viz dashboard is attention entropy per head:
          low entropy = sharp/focused (attends to one place), high entropy = diffuse (averages
          broadly). Ranking heads by entropy is a quick way to surface the interesting ones.

2. The logit lens

        

          A striking technique: apply the model's final unembedding (output head) to the
          residual stream at intermediate layers, projecting the hidden state into vocabulary
          space early. It reveals how the model's "current best guess" for the next token forms and
          sharpens layer by layer — often the prediction is roughly right well before the final layer.
          It's a one-liner given the weights, which is what makes it a great interactive-viz building
          block.

3. Linear probes & features

        

          To test whether a concept is linearly represented in the activations, train a simple
          linear classifier (a probe) on the hidden states to predict that concept. If a linear probe
          succeeds, the information is present and linearly accessible. The cell trains a probe to
          recover a planted concept direction from noisy activations.
        


        

          

            A linear probe finds a planted concept direction
            
            
            
          

          
          

        


        

          The frontier problem probes run into is superposition: models pack more
          features than they have neurons, so a single neuron responds to many unrelated concepts
          (polysemanticity). Sparse autoencoders (SAEs) address this by learning an
          over-complete, sparse dictionary of activation directions, aiming to recover
          monosemantic features — a major line of current interpretability research. Know the
          one-paragraph version: SAE encodes activations into a wide, sparse hidden layer and
          reconstructs them, so each sparse unit ideally corresponds to one human-interpretable feature.
        


        
        
4. Building the visualization (the sample project)

        

          If you set out to build an interactive internals visualizer, a strong design sketch:
        

        
    
          
  • Capture — register forward hooks to grab attention weights and residual
            activations per layer/head for a given input (no model changes, just taps).
    • 
          
  • Interaction — hover a token to see what it attends to; a layer/head
            selector; overlay the logit-lens top token per position per layer.
    • 
          
  • Summaries — rank heads by entropy or by a pattern score (previous-token,
            induction) so a user finds interesting heads without scrubbing all of them.
    • 
          
  • What makes it useful vs decorative — it should answer a question ("why
            did the model predict this token here?"), let you compare inputs, and scale to real models
            (aggregate/sample, don't render 96×96 heads raw).
    • 
        


        

          
The safety connection

          

            The safety community frames interpretability as an alignment lever: if we can read and eventually
            edit what models represent, we can monitor for deception, detect dangerous
            capabilities, and build trust that scales with capability. When motivation comes up, connect
            your interest to this — being able to say why interpretability matters for safe
            scaling, not just that it's neat, lands well here.
