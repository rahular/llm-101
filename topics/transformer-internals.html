Transformer Internals

The full decoder block, part by part. The goal: draw the data path from memory and justify every modern choice (pre-norm, RMSNorm, SwiGLU, RoPE) against its alternative. This page builds each component in PyTorch and assembles a working block.

Prerequisite

Attention itself lives on its own page — see Attention: Scratch → Efficient. Here we treat attention as a component and focus on everything around it that makes a transformer block.

1. The residual stream & block structure

The cleanest mental model (from the interpretability literature): a transformer is a residual stream — a running (batch, seqlen, d_model) activation that each sublayer reads from and writes back into via addition. A block is two sublayers, each wrapped in a residual connection:

x ← x + Attention(Norm(x))
x ← x + MLP(Norm(x))

Because every sublayer adds its output, information can flow untouched down the whole depth (the residual is an identity path), and each layer only has to learn a delta. This is what makes very deep stacks trainable.

Pre-norm vs post-norm

Where the normalization sits is one of the most consequential design choices, and a near-guaranteed question.

  • Post-norm (original Transformer): x ← Norm(x + Sublayer(x)). The normalization is on the residual path, so the identity signal gets rescaled every layer. Deep post-norm nets need careful LR warmup and often diverge without it.
  • Pre-norm (GPT-2 onward, now standard): x ← x + Sublayer(Norm(x)). The residual path is a clean identity; only the sublayer input is normalized. Gradients flow directly through the residual, so deep stacks train stably. The catch: the residual stream's variance grows with depth, which is why a final norm before the output head is needed.
Pre-norm keeps the gradient path clean 

        


        
        
2. Normalization: LayerNorm vs RMSNorm

        

          LayerNorm standardizes each token's feature vector to zero mean and unit variance, then
          applies a learned scale γ and shift β. RMSNorm (now dominant —
          Llama, most modern models) drops the mean-subtraction and the β: it just
          divides by the root-mean-square. It's cheaper (no mean, one fewer stat, no bias) and works
          as well or better, which is strong evidence the re-centering was doing little —
          the useful part is the re-scaling.
        

        

          LayerNorm: y = γ · (x − μ)/√(σ² + ε) + β 

          RMSNorm:   y = γ · x / √(mean(x²) + ε)

          A related trick worth naming: QK-norm — normalizing queries and keys before
          the attention dot-product — stabilizes attention logits and prevents the score blow-ups that
          cause loss spikes (see Training Dynamics).
        


        
        
3. The MLP / feed-forward block

        

          Each block's FFN is where most parameters live. Classic form: up-project to
          ~4×D, apply a nonlinearity, down-project back. Modern models use
          SwiGLU — a gated variant that splits the up-projection into two branches,
          gates one by the other's activation, and (to keep params matched) uses a hidden size of
          ~⅔·4D = 8D/3. SwiGLU consistently beats plain GeLU/ReLU FFNs at equal
          parameters, which is why it's near-universal now.
        

        

          GeLU FFN:  W₂ · GeLU(W₁x) 

          SwiGLU:    W₂ · ( SiLU(W₁x) ⊙ (W₃x) )

4. Positional information & RoPE

        

          Attention is permutation-invariant: shuffle the tokens and the raw attention math gives the
          same set of outputs. Position must be injected explicitly. The evolution:
        

        
    
          
  • Absolute (sinusoidal or learned): add a position embedding to the token
            embedding. Simple, but doesn't extrapolate past trained lengths and bakes position into
            the residual stream.
    • 
          
  • ALiBi: add a distance-proportional bias to attention scores. Cheap,
            extrapolates, but coarse.
    • 
          
  • RoPE (Rotary Position Embedding — the modern default): rotate
            each query/key vector by an angle proportional to its position. Its magic property: the
            dot product between a rotated query at position m and a rotated key at
            position n depends only on their relative distance
            m − n, not absolute positions. So attention becomes naturally
            relative-positional, and it extrapolates better than learned absolutes.
    • 
        


        

          

            RoPE from scratch — verify the relative-position property
            
            
            
          

          
          

        


        

          
Why this matters

          

            If asked "why does RoPE extrapolate?" — the rotation encodes relative position, so
            a model trained on short contexts has seen every small relative distance many times; long
            context mostly needs those same relative patterns at unseen absolute positions. Follow-ups
            probe context extension: NTK/position-interpolation tricks rescale the
            RoPE frequencies (base) so trained models handle longer contexts without full
            retraining. Knowing that lever exists reads as current.
          

        


        
        
5. Embeddings, the output head, and parameter counting

        

          The token embedding maps vocab → D; the unembedding (output head) maps
          D → vocab for the final softmax. Weight tying shares one
          matrix for both — saves V×D parameters and often helps quality. Being able to
          count a model's parameters cold is a common warm-up and underpins all the memory/scaling
          math on other pages.

7. Architectural variants: MoE

        

          A Mixture-of-Experts layer replaces the single FFN with E expert FFNs plus a
          router that sends each token to its top-k experts (usually
          k=1 or 2). This decouples total parameters from active parameters per
          token: you get a much larger model at nearly the FLOPs of a small one. The central problem
          is load balancing — without pressure, the router collapses onto a few
          experts. An auxiliary load-balance loss pushes token assignments to be even
          across experts.
        

        

          aux_loss = E · Σᵢ fᵢ · Pᵢ    (fᵢ = fraction of tokens routed to expert i,
          Pᵢ = mean router prob for expert i)
        


        

          

            Top-1 routing + load-balance loss
            
            
            
          

          
          

        

        

          Also know at a sentence's depth: GQA/MQA (shared KV heads — see
          Attention) and state-space models (Mamba):
          sequence mixing via a linear recurrence/selective scan instead of attention, giving
          O(T) inference and no KV cache, at some cost to in-context recall.
        


        

          

            Exercise
            Design a Transformer-variant ablation
            
          

          

            The classic architecture-research exercise. Pick one axis (RMSNorm vs LayerNorm, SwiGLU vs GeLU, RoPE
            vs learned-absolute) and design the controlled experiment to compare them: what you hold
            fixed (params, FLOPs, tokens, LR schedule), model/proxy size, which metrics, how many
            seeds for noise, and how you'd decide the winner. Ties into
            Scaling Laws & Experiment Design.
          

        


        

          

            Local exercise
            Build a modern block in PyTorch and train nanoGPT-scale
            
          

          

            On your machine: implement a pre-norm block with RMSNorm + RoPE + SwiGLU in PyTorch, stack
            it into a small GPT, and train on a toy corpus (Shakespeare/enwik8). Confirm loss drops and
            generation is coherent. Then swap one component (e.g. RMSNorm→LayerNorm) and compare — a
            hands-on version of the ablation above and the best way to make all of this reflexive.
