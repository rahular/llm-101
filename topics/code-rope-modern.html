RoPE & Modern Blocks

The upgrades that turn the standard GPT into a modern Llama-style model: RMSNorm instead of LayerNorm, RoPE instead of a learned position table, and a SwiGLU MLP. Concepts are on Transformer Internals; here is the code.

1. RMSNorm

Normalize by the root-mean-square over the feature dim — no mean subtraction, no bias. Cheaper than LayerNorm and just as effective.

2. RoPE — rotary position embeddings

RoPE injects position by rotating query/key vectors by an angle proportional to their position, so the attention dot product depends only on the relative offset. This is the rotate_half formulation (as in HuggingFace Llama): precompute cos/sin once, then apply inside attention.

3. SwiGLU MLP

        

          A gated feed-forward: one branch gates the other via SiLU. Hidden size is set to
          ~8·dim/3 so the three matrices roughly match a plain 4× FFN's parameter count
          (Transformer Internals §3).
        

        


        


        
        
4. Attention with RoPE (via SDPA)

        

          Separate Q/K/V projections, apply RoPE to Q and K after the head split, then call
          scaled_dot_product_attention with is_causal=True — the fused
          FlashAttention path. No mask buffer needed; SDPA builds the causal mask internally.
        

        


        


        
        
5. The block, and wiring the model

        

          Same pre-norm structure as the standard block, but with RMSNorm, RoPE attention, and SwiGLU.
          Crucially there is no positional embedding table — position lives entirely in
          RoPE, which the model precomputes once and threads through every block.
        

        


        


        
        
6. Beyond RoPE: NoPE and YaRN


        
NoPE — no positional encoding at all

        

          A surprising fact: a causal decoder needs no explicit positional encoding to know
          where tokens are. The causal mask already breaks permutation symmetry — position t
          sees a different prefix than position t+1, and the model can (and does) learn to
          recover position from that alone, e.g. by measuring how much attention mass a query collects
          from the always-visible early tokens. Kazemnejad et al. (2023) showed NoPE decoders not only
          train fine but length-generalize better than RoPE on algorithmic tasks —
          there are no learned frequencies to go out-of-distribution at unseen lengths.
        

        


        

        

          Production models use NoPE selectively, not wholesale: Llama 4's "iRoPE" interleaves
          RoPE layers (local, chunked attention) with NoPE global-attention layers —
          the position-free layers are the ones that extrapolate to very long context. Thinking
          Machines' Inkling goes further and drops RoPE entirely in favor of a learned relative bias
          (case study). The design intuition: rotation-based
          position helps local precision, but at long range it mostly adds an extrapolation liability.
        


        
YaRN — extending a trained model's context

        

          You trained at 4K and want 128K. Naive options both fail: extrapolating RoPE past trained
          positions produces angles the model has never seen, and uniformly interpolating all positions
          into the trained range (Position Interpolation) squeezes the fast dimensions so much
          that nearby tokens become indistinguishable. YaRN (Peng et al., 2023) fixes
          this by treating RoPE's dimensions by wavelength — "NTK-by-parts":
        

        
    
          
  • High-frequency dims (wavelength ≪ trained context — they complete many
            rotations): don't touch them. They encode local order, and interpolation would
            destroy it.
    • 
          
  • Low-frequency dims (wavelength ≥ trained context — under one full
            rotation): fully interpolate (divide frequency by the scale factor s).
            They encode coarse position and interpolate safely.
    • 
          
  • In between: a linear ramp mixes the two.
    • 
          
  • Plus an attention temperature: scale cos/sin by
            mscale = 0.1·ln(s) + 1, which sharpens logits to compensate for the longer
            context's entropy increase.
    • 
        

        


        

        

          Scaling cos/sin by mscale multiplies every q·k logit by mscale² —
          the temperature applied where it's cheapest. In practice YaRN needs only a brief
          fine-tune at the new length (or even works zero-shot at modest scales); Kimi K2.5 used YaRN
          for its long-context activation to 262K (case study).

Reading checklist

          

            Trace the differences from the standard GPT: RMSNorm (no mean/bias), RoPE applied to Q/K
            inside attention (no learned position table), SwiGLU's three matrices with the 8·dim/3 hidden
            size, and SDPA replacing the manual mask+softmax. These four swaps are essentially "GPT-2 →
            Llama." Then the two positional extremes: NoPE (delete the rotation — the causal mask alone
            carries position, and it length-generalizes) and YaRN (stretch a trained model's context by
            interpolating only the slow RoPE dims, plus the 0.1·ln(s)+1 temperature).
