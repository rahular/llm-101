Standard Transformer

A complete, readable decoder-only GPT in PyTorch — the nanoGPT lineage. Read it top to bottom: config → attention → MLP → block → model. Every piece maps to the concepts on Attention and Transformer Internals; this page is the working code for them. Use the copy button on any block to paste it into your editor and run it.

How to use this section

These blocks are PyTorch (which can't run in the browser), so they're for reading and copying. The occasional green Run cell is a runnable PyTorch check against the local kernel. Pair this with the Local exercise prompts to actually train it.

2. Causal self-attention

The heart of the model. One fused QKV projection, reshape into heads, scaled dot-product with a causal mask (positions can't see the future), softmax, weighted sum of values, then re-assemble heads and project out. Shapes are annotated at every step — narrating shapes is the habit that keeps transformer code correct.

⚠️ In production, use SDPA

The explicit scores → mask → softmax above is written for clarity. Real code replaces it with F.scaled_dot_product_attention(q, k, v, is_causal=True), which dispatches to a fused FlashAttention kernel — same math, far less memory and HBM traffic (see Attention: Scratch → Efficient). The next page uses SDPA.

3. The MLP

        

          A two-layer feed-forward network with a 4× hidden expansion and a GELU nonlinearity — where
          most of a transformer's parameters live.
        

        


        


        
        
4. The block (pre-norm)

        

          Two sublayers, each wrapped in a residual connection with the norm applied to the
          input of the sublayer (pre-norm) — the clean identity path that lets
          deep stacks train. See Transformer Internals §1 for
          why pre-norm beats post-norm.
        

        


        


        
        
5. The full model

        

          Token + learned positional embeddings, the stack of blocks, a final norm, and the language-model
          head. Note weight tying (the embedding and unembedding share one matrix) and
          the small-normal init. The forward returns logits and, if targets are given, the
          cross-entropy loss — computed directly from logits for numerical stability
          (Numerics).
