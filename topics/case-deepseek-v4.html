Case Study: DeepSeek-V4

The most technically dense open release of 2026: 1.6T-parameter MoE (49B active) trained on ~33T tokens, with a hybrid compressed-attention design that makes 1M-token context tractable. Every section below is a transferable technique — each maps back to a concept page on this site.

The two models

V4-Pro: 1.6T total / 49B active, 33T tokens. V4-Flash: 284B / 13B active, 32T tokens. At 1M context, Pro runs at 27% of the inference FLOPs and 10% of the KV cache of DeepSeek-V3.2 (Flash: 10% / 7%), and KV storage is ~2% of a bf16 GQA-8 baseline.

1. Hybrid compressed attention: CSA + HCA

V4 interleaves two attention variants, both operating on compressed KV streams — a third escape route from the KV-cache wall beyond the linear-hybrid (Qwen/Kimi) and local/global (Inkling) families on Attention Variants:

  • CSA (Compressed Sparse Attention) — compress every m tokens into one KV entry, then run sparse top-k selection over the compressed entries using a low-rank "Lightning Indexer", plus a sliding window of recent uncompressed tokens for local fidelity.
  • HCA (Heavily Compressed Attention) — compress much more aggressively (m′ ≫ m) and attend densely over the small compressed stream. Cheap global gist.

Both use shared-KV MQA with grouped output projections, partial RoPE (only the last 64 dims), and an attention sink. The interleave gives you precise recent detail (window), selective long-range recall (CSA top-k), and cheap global context (HCA) — without an uncompressed O(seqlen) cache anywhere.

Why compression beats GQA alone at 1M context 

        


        
        
2. mHC: making a 1.6T model trainable

        

          Hyper-connections generalize the residual stream (Transformer
          Internals §1): instead of plain x + f(x), layers mix multiple residual lanes
          through a learned matrix. Unconstrained, that mixing matrix can amplify signals and destabilize
          very deep/large models. V4's manifold-constrained hyper-connections (mHC)
          project the mixing matrix onto the doubly-stochastic manifold (rows and columns sum
          to 1, via ~20 Sinkhorn-Knopp iterations), guaranteeing spectral norm ≤ 1 — the residual mix can
          redistribute signal but never blow it up. Cost: ~6.7% wall-time inside an overlapped pipeline
          stage. The claim: without mHC, 1.6T + hybrid attention wouldn't train reliably.
        

        

          File this with the stability toolkit on Training Dynamics §3
          — same family as QK-clip and z-loss: bound the thing that can explode, by construction.
        


        
        
3. Anticipatory routing: MoE without the routing stall

        

          MoE routing is a sequential bottleneck: you can't dispatch tokens (the all-to-all) until the
          router has run. V4 decouples features from routes — expert inputs are
          computed with current weights, but the routing indices come from a slightly older
          router: a future batch is prefetched, routed early with the old router, and the decisions are
          cached. By the time the batch trains, its routes are already known, so communication can be
          scheduled ahead (Distributed §2–3). A one-step-stale router
          costs almost nothing in quality but unlocks full overlap.
        

        

          Other MoE details worth quoting: fine-grained + shared experts (the DeepSeekMoE signature),
          Sqrt(Softplus) replacing sigmoid for router affinities, hash
          routing in the first layers (deterministic, learn-free load balance where features are
          still generic), and FP4 expert weights via quantization-aware training.
        


        
        
4. Muon, industrialized

        

          The Muon recipe at 1.6T scale:
        

        
    
          
  • Hybrid Newton–Schulz schedule: 8 steps of the tuned quintic
            (3.4445, −4.7750, 2.0315) then 2 steps of (2, −1.5, 0.5) — a polish phase for a tighter
            orthogonalization than the standard 5 steps.
    • 
          
  • AdamW for the usual exceptions — embeddings, heads, RMSNorm gains, and
            mHC's static components.
    • 
          
  • Distributed plumbing: Muon needs the full gradient matrix per
            weight, which conflicts with ZeRO's flat sharding — so a hybrid bucketing scheme keeps
            Muon-owned matrices gatherable. MoE gradients are communicated in bf16 with
            stochastic rounding, then summed locally in fp32.
    • 
        


        
        
5. The precision ladder

        

          V4 treats precision per-tensor-role, an aggressive extension of
          Numerics: bf16 for the RoPE dims of K (position must
          stay accurate), fp8 for the rest of the KV cache, fp4 for the
          indexer path, and fp4 expert weights (QAT). The lesson to
          articulate: precision is a budget allocated by sensitivity, not a global switch.
        


        
        
6. Post-training: specialists → on-policy distillation

        

          The pipeline is exactly the pattern from
          On-Policy Self-Distillation, at production scale:
          train independent domain specialists (math, coding, agent, instruction
          following) via SFT → GRPO, then distill them all into one unified model with
          full-vocabulary on-policy distillation (reverse KL). Specialists can be pushed
          hard without worrying about interference; OPD merges them without the forgetting that
          sequential SFT would cause.
        


        
        
7. Infrastructure notes that signal depth

        
    
          
  • Batch-invariant, deterministic kernels — dual-kernel attention, DeepGEMM
            over cuBLAS, deterministic reductions in sparse-attention/MoE backward. Run-to-run
            reproducibility at scale (Numerics §5 made real).
    • 
          
  • Wave-based expert parallelism with fine-grained comm/compute overlap:
            1.5–1.96× inference speedup.
    • 
          
  • TileLang DSL with an SMT solver (Z3) for kernel integer analysis; host
            codegen gets launch overhead under 1µs.
    • 
          
  • Two-stage context parallelism for compressed attention: ranks exchange the
            last m uncompressed KV entries, compress locally, then all-gather.
    • 
        


        

          
The one-breath summary

          

            The V4 story in one breath: "solve long context by compressing the KV stream twice over
            (sparse-selective + heavy-dense), stabilize a 1.6T model by construction (doubly-stochastic
            residual mixing, QAT), hide MoE routing latency by using slightly stale routes, and
            post-train specialists then merge them by on-policy distillation." Each clause is a
            transferable principle, not a V4-specific fact.
