Case Study: Qwen 3.6

The cleanest production validation of the linear-attention hybrid thesis from Attention Variants: three quarters of the network is Gated DeltaNet, and the models are aggressively tiny-active MoE — a 35B model that runs 3B of parameters per token and still "thinks, codes, and agents" like something much bigger.

1. The 3:1 hybrid, as a repeating macro-block

Qwen 3.6's layer stack is literally a tiling of one pattern:

35B-A3B: 10 × [ 3 × (Gated DeltaNet → MoE) → 1 × (Gated Attention → MoE) ]
27B dense: 16 × [ 3 × (Gated DeltaNet → FFN) → 1 × (Gated Attention → FFN) ]

75% of sublayers are linear attention (fixed-size recurrent state, no KV-cache growth), and every fourth attention layer is full softmax attention for exact long-range recall. Qwen's reported ablation is the fact to memorize: the 3:1 hybrid outperforms either monolithic architecture — better than all-DeltaNet and better than all-softmax — while being far cheaper at long context. Hybridization isn't a compromise; it's the optimum.

⚠️ The detail most people miss: asymmetric heads

In the 27B dense variant, the linear-attention layers use 48 heads for V but only 16 for Q/K (head_dim 128). The DeltaNet state is a per-head (head_dim × head_dim) matrix — value capacity is what the fixed state is short of, so Qwen spends heads where the memory bottleneck actually is, rather than keeping the symmetric Q/K/V head count softmax attention defaults to.

2. Tiny-active MoE

35B total / 3B active is ~8.6% activation — and the smaller sibling of a field-wide race toward extreme sparsity (see the synthesis page for the cross-model table). The practical framing: total parameters set what the model knows; active parameters set what a token costs. Qwen's bet is that a consumer-deployable cost point (3B active) can carry near-frontier capability if the knowledge pool behind it is 10× larger.

3. Multi-step MTP → self-speculative decoding

Qwen 3.6 trains multi-token prediction with multiple steps — auxiliary heads predicting several future tokens, not just one. Besides the usual MTP training-signal benefit, the multi-step heads double as a built-in draft model: at inference the model drafts several tokens ahead with the cheap MTP heads and verifies them with the full forward pass — self-speculative decoding with no separate draft network to train, deploy, or keep in sync. Speculative decoding's usual ops problem (maintaining a second model) disappears.

4. Long context as a default, not a variant

Native context is 262K, extendable to ~1M. This is what the 3:1 hybrid buys: with 75% of layers holding a fixed-size state, the KV cache only grows in a quarter of the layers, so long context stops being a memory catastrophe (KV-Cache Inference §6). The full-attention layers — the only ones paying the growing-cache cost — are exactly the ones providing verbatim recall.

Why this matters

Qwen 3.6 is the model to cite when asked "would you use linear attention in production?" — the answer is the ratio, not the religion: "Qwen 3.6 ships 75% Gated DeltaNet / 25% softmax and their ablations show the hybrid beats both extremes; the full-attention layers carry recall, the linear layers carry cost." Bonus points for the asymmetric-head detail and for MTP-as-free-draft-model, which shows you think about inference economics, not just training loss.

Checklist before you call this "sharp"

You can: (1) write out the 3:1 macro-block pattern and state the hybrid-beats-both ablation; (2) explain why V gets more heads than Q/K in the linear layers; (3) explain multi-step MTP and how it enables self-speculative decoding; (4) connect 75% fixed-state layers to 262K-native context; (5) frame total-vs-active params as knowledge-vs-cost.
